  ВИКТОРИНА МОСКАБЕЛЬМЕТ — Telegram Mini App
  Репозиторий: https://github.com/Dion-alt-ru/moskabelmet-game
================================================================

ОПИСАНИЕ
--------
Интерактивная викторина о компании Москабельмет, реализованная
как Telegram Mini App.


ВОЗМОЖНОСТИ
-----------
- 15 вопросов по темам: история компании, кабельные технологии,
  IT-инфраструктура, крупные проекты
- Система очков с бонусом за серию правильных ответов (streak)
- Перемешивание вариантов ответов при каждом запуске
- После каждого ответа — объяснение и интересный факт
- Итоговый экран с достижением, точностью и максимальной серией
- Работает и вне Telegram (в обычном браузере)


БЫСТРЫЙ СТАРТ
-------------
1. Клонируй репозиторий:
   git clone https://github.com/Dion-alt-ru/moskabelmet-game.git

2. Открой index.html в браузере — никаких зависимостей не нужно.

Для подключения к Telegram боту:
1. Создай бота через @BotFather
2. Размести index.html на хостинге с HTTPS
   (GitHub Pages, Vercel, Netlify и т.д.)
3. В BotFather используй /newapp и укажи URL файла
4. Mini App готово!


СТРУКТУРА ПРОЕКТА
-----------------
moskabelmet-game/
└── index.html    (всё приложение: HTML + CSS + JS в одном файле)


ГЕЙМПЛЕЙ
--------
  Вопросов:              15
  Очков за вопрос:       100
  Бонус за серию:        +10 за каждый последующий верный ответ
  Максимум очков:        1500+ (с учётом бонусов)
  Примерное время:       ~5 минут

Достижения по результату:
  100%      — Легенда знаний
  80–99%    — Знаток технологий
  60–79%    — Технический специалист
  40–59%    — Начинающий
  менее 40% — Новичок


ДАННЫЕ, ОТПРАВЛЯЕМЫЕ БОТУ
--------------------------
После завершения викторины приложение отправляет боту:

  score      — итоговые очки
  correct    — количество правильных ответов
  total      — всего вопросов
  percentage — точность в процентах
  maxStreak  — максимальная серия
  game       — "quiz"


КАК ДОБАВИТЬ СВОЙ ВОПРОС
-------------------------
Открой index.html и добавь объект в массив questions:

  {
      question: "Текст вопроса?",
      options: ["Вариант 1", "Вариант 2", "Вариант 3", "Вариант 4"],
      correct: 0,     // индекс правильного ответа (0–3)
      fact: "Интересный факт после ответа.",
      points: 100
  }


ТЕХНОЛОГИИ
----------
- Vanilla JavaScript (без фреймворков)
- CSS (glassmorphism, анимации, адаптивная вёрстка)
- Telegram Web App SDK
- Google Fonts (Inter)


ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ
---------------------
